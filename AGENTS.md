# Project guidance

This repository is an intentionally empty product template.

- Begin product work with the repository's `finn-spec` skill.
- Do not choose a framework or create application code before the first
  specification is approved.
- Use `finn-build` only for an approved `agent-ready` Linear issue.
- Run `finn-review` in a separate fresh chat from the builder.
- Keep secrets in `.env`; never commit that file.
- Treat the approved Linear issue as the implementation contract.
